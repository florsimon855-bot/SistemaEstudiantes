Sistema de Gestión de Estudiantes

Descripción
Esta aplicación fue desarrollada en Java y permite mostrar la información básica de un estudiante, como su nombre, edad y carrera.

Objetivo
Aplicar los conceptos fundamentales de la programación orientada a objetos, utilizando clases, atributos, constructores, métodos y objetos.

Tecnologías utilizadas
- Java JDK 21
- Visual Studio Code
- Git y GitHub

 Funcionamiento
La aplicación crea un objeto de la clase `Estudiante` y muestra sus datos en la terminal.

Cómo ejecutar
1. Instalar Java JDK 21 o una versión compatible.
2. Descargar el archivo `Main.java`.
3. Abrir una terminal en la carpeta del archivo.
4. Ejecutar el comando:

`java Main.java`

Conceptos de programación orientada a objetos
* Clase: `Estudiante`.
* Atributos: nombre, edad y carrera.
* Constructor: inicializa los datos del estudiante.
* Método: `mostrarDatos()`, que imprime la información.
* Objeto: `estudiante1`, creado en el método `main()`.
